GPU QUEUE · 为有条理的实验而设计顺序优先 · 空闲复用 · 失败即停
AGENT → QUEUE

一个入口，连接你的 Agent。

Codex 和 Claude 准备代码、数据与环境，生成任务文件，通过同一个提交工具进入任务台。

准备任务→CPU 检查→提交队列→你点开始
gpuq validate --manifest <任务文件绝对路径>
gpuq submit --manifest <任务文件绝对路径> --source codex

提交后任务会直接出现在这里。Agent 无法通过提交工具批准执行；你点开始后，服务器才会进入资源流程。

停止这个任务？

排队中的任务会移出队列；运行中的任务会结束当前步骤和子进程，后续步骤不再执行。已写入的产物保留，尚未写入的结果可能丢失。

停止任务不等于释放 GPU 或撤回已提交的资源申请。再次运行需要提交新版本并重新点击开始。
