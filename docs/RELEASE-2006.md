适用 Apple Silicon、macOS 13+，连接公司已开通的个人 Linux CPU 账号。Windows 暂不提供安装包。

本版包含：
- 首次接入引导、添加个人服务器入口与员工安装指南。
- 分别检查 SSH、个人任务服务身份和调度心跳的连接诊断。
- 总览优先显示待处理事项，可筛选待开始、等待资源、执行中与需核查任务。
- 任务下一步建议，以及不含日志和路径的 Agent 排查摘要。
- 兼容现有服务的真实提交/步骤活动时间，明确显示 4090/H卡类型及未指定显存。
- 切换连接目标时隐藏原账号任务快照；不兼容的状态响应阻止操作。
- 个人服务安装工具默认只检查，显式安装只登记停用服务，拒绝覆盖已有配置；不登录、不申请 GPU。
- 保留版本校验、SHA-256 校验和失败回滚的应用内更新机制，合入 4090 申请失败回执识别修复。

首次安装：下载 DMG 与 SHA256SUMS，核对校验和后将 GPU Queue.app 放到本人可写的 `~/Applications`，双击启动。不要复制别人的客户端数据、私钥或账号配置。详见随包 EMPLOYEE-SETUP.md。已有用户可通过应用内检查更新安装；升级将重启客户端，本地终端会断开，远端任务继续运行。

此包采用 ad-hoc 签名，未进行 Apple Developer ID 签名与公证，首次打开可能需由员工确认系统信任提示。它是内部可用发行包，不是免提示的企业托管分发包。客户端不替代管理员开户或本人飞书授权；GPU 回收以平台回执为准，不能把任务结束理解为资源已释放。

构建与自动化测试结果见 native-report.json、installer-report.json；完整 Mac 首开与真实连接验收另见发布附件。只读验收不申请 GPU，不重复运行已有任务。
