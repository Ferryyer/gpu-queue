# Inspire Queue 2.0.2017

- 在新用户配置和「服务器 → ＋ → 飞书登录接入」使用本人飞书账号连接个人服务器。应用会自动生成本机设备密钥并配置连接，员工无需手动选择私钥或导入配置包。
- 授权页与客户端显示同一设备确认码。本人确认后可使用现有任务、终端和文件功能。首次接入需要管理员已开通个人服务器及飞书身份绑定。
- 此版设备授权随本次网页登录会话生效，最长 8 小时。授权到期后可重新登录；接入页可查看到期时间及「退出此设备」。
- 已有同账号服务器时，应用会先确认是否更新连接。

适用于 Apple Silicon Mac（macOS 13 及以上）。安装包采用 ad-hoc 签名，未进行 Apple 公证。
