## 关于页面与单向历

- About 的制作人与贡献名单统一显示 Ferryyer，链接到本人的 GitHub 主页。上游项目链接、开源许可证和地图数据来源继续保留。
- 单向历改为应用自带脚本下载，与 Codex、桌面自动化和开发环境完全脱离。启动、跨天、唤醒后检查；当天成功后不重复下载或重载图片，失败半小时后重试，离线保留缓存。
- 本机识别图片的年月日，拒绝把旧图当成今日图片；兼容来源偶尔把图片放在次日文件名的情况。图片来源可直接查看，个人 AI 出处笔记不包含在分发版本中。
- 飞书独立页和总览内嵌页使用不同的布局适配：独立页保留飞书原生定位，仅应用基础主题和导航清理；总览使用窄屏任务导航。浏览器推荐条通过自身关闭按钮收起，让飞书同步更新布局状态。
- 保留 2011 版本的 GPU 任务清理、飞书任务及总览布局。

适用：Apple Silicon Mac，macOS 13 及以上。当前为 ad-hoc 签名，未完成 Apple 公证。

首次使用请阅读附件 `EMPLOYEE-SETUP.md`，配置自己的服务器账号与个人任务服务，并自行登录飞书。个人日历、笔记、账号及任务不包含在安装包中。
