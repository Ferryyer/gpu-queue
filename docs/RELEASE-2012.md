## 关于页面与单向历

- About 的制作人与贡献名单统一显示 Ferryyer，链接到本人的 GitHub 主页。上游项目链接、开源许可证和地图数据来源继续保留。
- 单向历取消每分钟自动刷新。首次打开时读取桌面图片，之后由右上角刷新按钮手动更新，避免阅读时反复重载。
- 保留 2011 版本的 GPU 任务清理、飞书任务及总览布局。

适用：Apple Silicon Mac，macOS 13 及以上。当前为 ad-hoc 签名，未完成 Apple 公证。

首次使用请阅读附件 `EMPLOYEE-SETUP.md`，配置自己的服务器账号与个人任务服务，并自行登录飞书。个人日历、笔记、账号及任务不包含在安装包中。
