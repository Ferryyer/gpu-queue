# Inspire Queue 2.0.2016

- 在「GPU 任务 → 任务详情 → 结果」点产物旁的文件夹按钮，即可在应用内打开该产物所在的远端目录。原有的复制路径按钮仍可使用。
- 结果目录默认使用当前任务服务的 SSH 账号访问。任务已关联访问服务器时，使用关联的服务器。目录不存在或权限不足时，文件浏览器会显示原因。
- 包含 2.0.2015 的 Mac 应用内更新修复。如果旧版本更新时仍提示退出超时，可退出应用并用 DMG 中的新应用替换原应用。

适用于 Apple Silicon Mac（macOS 13 及以上）。安装包采用 ad-hoc 签名，未进行 Apple 公证。
