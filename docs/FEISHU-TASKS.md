# 飞书任务

Inspire Queue 的左侧新增“飞书任务”，与服务器、终端并列，总览首页保留。
Mac 版本直接打开飞书任务网页，首次使用在飞书页面完成登录，登录状态由本机 WebKit 保存。
应用不会读取、转存或发送飞书密码、Cookie、授权码与任务内容。

## 页面操作

- 顶栏提供后退、刷新、在浏览器打开；“页面选项”可回到“我负责的”，或关闭 Inspire 风格恢复飞书原版。
- Inspire 风格沿用应用的暖白、炭灰、陶土色，跟随应用深浅主题。
- 隐藏飞书最左侧全局导航，去除任务操作区的深色留边。
- 独立飞书页保留原生任务布局和定位，仅应用基础主题与全局导航清理。
- 总览内嵌页的内容区不超过 760px 时，任务导航收进“任务导航”按钮；展开后可选清单，Esc 收起并恢复按钮焦点。
- 浏览器体验推荐条通过自身关闭按钮收起，不直接用 CSS 隐藏提示容器。
- 任务列表保留飞书本身的交互和横向滚动，不删除字段或修改任务数据。
- 其他平台暂使用系统浏览器；Windows 内嵌网页尚未交付。

## 油猴脚本

`serverbox/assets/feishu/inspire-task.user.js` 是应用内置样式与独立油猴脚本的同一份源文件，
基于用户提供的“飞书任务：隐藏全局导航” v1.1.0 改造。
仅在配置的飞书租户任务路径生效；登录页与其他飞书页面保持原样。
独立安装时，油猴菜单可切换 Inspire 风格与飞书原版。

## 维护与验收

脚本通过任务导航链接识别侧栏，避免绑定飞书压缩后的 CSS 类名。
如果飞书改变结构导致识别失败，将保留原有侧栏；可随时关闭样式。
原生层没有网页到本机文件/终端的脚本桥接，也不放宽 TLS 校验。
普通站外链接由系统浏览器处理，下载和上传使用系统文件选择窗口。
企业自定义身份提供商的登录可能需要在浏览器完成；建议使用飞书扫码登录。

本功能的单元测试不代替真实账号登录验收。安装包验收应覆盖：首次扫码、重启保持登录、
任务页与其他标签来回切换、窄/宽窗口、深色模式、原版恢复与附件操作。
