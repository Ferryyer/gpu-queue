# 飞书任务

Inspire Queue 的左侧新增“飞书任务”，与服务器、终端并列，总览首页保留。
Mac 版本直接打开飞书任务网页，首次使用在飞书页面完成登录，登录状态由本机 WebKit 保存。
应用不会读取、转存或发送飞书密码、Cookie、授权码与任务内容。

主界面与侧栏统一为系统 WebKit 补齐 Safari 版本标识，避免被浏览器类型检查误判为“不支持该浏览器”。版本优先读取本机 Safari；无法读取时使用应用最低系统 macOS 13 对应的保守版本标识。首次导航等待视图获得有效尺寸，登录弹窗沿用相同标识。

依据：[飞书支持的浏览器](https://www.feishu.cn/hc/en-US/articles/360040080753-use-the-web-version-of-feishu?slug=true)列出 Safari 最低版本；[WebKit 问题 278284](https://bugs.webkit.org/show_bug.cgi?id=278284)记录 macOS WKWebView 默认缺失 Safari 版本标识。尚需真实账号验收，以确认用户遇到的提示已消失。

## 页面操作

- 顶栏提供后退、刷新、在浏览器打开；“页面选项”可回到“我负责的”，或关闭 Inspire 风格恢复飞书原版。
- Inspire 风格沿用应用的暖白、炭灰、陶土色，跟随应用深浅主题。
- 隐藏飞书最左侧全局导航，去除任务操作区的深色留边。
- 独立飞书页保留原生任务布局和定位，仅应用基础主题与全局导航清理。
- 总览内嵌页的内容区不超过 760px 时，任务导航收进“任务导航”按钮；展开后可选清单，Esc 收起并恢复按钮焦点。
- 浏览器体验推荐条通过自身关闭按钮收起，不直接用 CSS 隐藏提示容器。
- 任务列表保留飞书本身的交互和横向滚动，不删除字段或修改任务数据。
- 总览内嵌页和侧栏独立页每三小时尝试刷新一次；应用休眠或退到后台时暂停，超过刷新时间后回到前台只补刷新一次。登录页、正在加载的页面和附件选择窗口打开时跳过定时刷新。
- 网页进程退出后，在应用前台且视图回到窗口时自动恢复一次；若恢复仍失败，可点击顶栏刷新重试。首次加载失败而没有可重载页面时，刷新会重新打开“我负责的”。
- 其他平台暂使用系统浏览器；Windows 内嵌网页尚未交付。

## 油猴脚本

`serverbox/assets/feishu/inspire-task.user.js` 是应用内置样式与独立油猴脚本的同一份源文件，
基于用户提供的“飞书任务：隐藏全局导航” v1.1.0 改造。
仅在配置的飞书租户任务路径生效；登录页与其他飞书页面保持原样。
独立安装时，油猴菜单可切换 Inspire 风格与飞书原版。

## 维护与验收

脚本通过任务导航链接识别侧栏，避免绑定飞书压缩后的 CSS 类名。
如果飞书改变结构导致识别失败，将保留原有侧栏；可随时关闭样式。
原生层没有网页到本机文件/终端的脚本桥接，也不放宽 TLS 校验。
普通站外链接由系统浏览器处理，下载和上传使用系统文件选择窗口。
企业自定义身份提供商的登录可能需要在浏览器完成；建议使用飞书扫码登录。

本功能的单元测试不代替真实账号登录验收。安装包验收应覆盖：首次扫码、重启保持登录、
任务页与其他标签来回切换、窄/宽窗口、深色模式、原版恢复与附件操作。

本次恢复行为还需 Mac 实机验收：让总览页与侧栏页分别加载后切换、模拟 WebKit 内容进程退出、休眠超过三小时后返回，并检查登录页与附件窗口不被定时刷新打断。CPU Widget 测试覆盖三小时间隔、十小时后台后的单次补刷新、短暂失焦与销毁后取消定时器，不能证明真实飞书账号错误已复现或修复。

在准备好的 Mac 上运行 `python3 scripts/test_feishu_browser.py` 可编译真实视图源码（仅替换 Flutter 消息接口），使用本地空白 HTML 检查实际 WebKit 的浏览器标识、零尺寸时不导航、持久数据存储与错误状态。该检查不登录飞书，不能替代安装包和真实账号验收。
