# 成果网页转发

在「服务器」选择运行成果网页的服务器，打开「端口转发」，点击「打开成果链接」。粘贴 Codex 给出的 `http://127.0.0.1:8780/...` 链接，点击「建立转发并打开」。

Queue 复用服务器连接，将本机 `127.0.0.1:8780` 接到所选服务器的 `127.0.0.1:8780`，随后打开浏览器。也支持 `localhost` 和 HTTPS 链接。配置会保存；相同目标的配置和已开启的转发会复用。

同一个 8780 服务下的所有成果路径、图片、脚本和 WebSocket 都使用这条 TCP 转发，不必每个成果单独配置。服务器上的成果服务需要由原有工具启动并持续运行；转发不会启动网页服务，也不会自动把其他端口的服务归并到 8780。

可以告诉远程 Codex：

> 请把成果放在已有的 8780 成果服务下，使用不同目录区分项目，并给我完整的 http://127.0.0.1:8780/ 链接。不要为每份成果另开端口，也不要覆盖已有服务。

本机 8780 同时只能连接一个目标。如果端口已被占用，Queue 会显示错误，保留原服务。可在转发列表关闭已有转发再重试。退出 Queue 或 SSH 断开后，再次「打开成果链接」可重新建立转发；当前没有后台自动重连。

转发仅监听本机回环地址，不向局域网开放。访问者仍然使用本人保存的服务器连接和认证方式。
