应用内安装从 2.0.2004 起提供。2.0.2003 及更早版本仍须手动下载并覆盖一次，以获得安装器。

检查更新后点击“下载并安装”，应用显示下载和校验进度，再退出、替换并重启。更新会断开本地 SSH 终端连接，远端任务继续运行。安装器不修改用户配置、钥匙串或服务器代码。

安装前验证正式 GitHub tag 的精确版本资产、字节数和 SHA-256，原生进程再次校验摘要、DMG、bundle ID、递增 build、CPU 架构及代码签名。只有准备好同目录暂存副本后才要求应用退出。不能写入当前应用目录时保留原应用，并提示迁移至可写的 Applications 文件夹；不使用 sudo，也不改动 Gatekeeper 设置。

独立的 `Contents/Helpers/GPUQueueUpdater` 等待旧进程退出，将原应用移至同目录的 `Inspire Queue.previous-<build>-<UUID>.app`，放入新版并启动。新版首次渲染后通过原生通道确认启动。45 秒内无确认则停止本次启动的新进程、恢复备份并重开旧版。退出超时或取消不会替换应用。突然断电、安装器被外部终止等情况可能需要从备份手动恢复。

状态和日志位于用户的 `Library/Application Support/Inspire Queue/Updater` 中。失败后可通过设置重新检查更新；如已回滚，下一次打开会提示结果。旧版备份保留供用户自行清理。

`scripts/test_mac_updater.py` 必须在真实 Mac 前台会话中运行。它编译生产安装器，构造并签名临时 app/DMG，验证正常更新重启、错误摘要、错误 bundle ID、退出超时、启动回滚和取消。发布流程只有在六项测试及完整原生构建通过后才打包发布，相关报告随 Release 提供。测试使用隔离的临时应用，不访问真实应用、SSH 或钥匙串。
