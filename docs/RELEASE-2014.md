# Inspire Queue 2.0.2014

- GPU 任务页在服务器启用「自动连接」时会尝试恢复断开的 SSH 连接，并重新同步任务列表和调度心跳。临时网络故障会间隔重试，需确认主机指纹或补充 SSH 凭据时可点「重新检查」。
- 连接诊断会区分 SSH、个人任务服务和调度心跳。重新连接只刷新状态，避免重复发送开始、停止等任务操作。
- 个人任务服务源码包含 GPU 任务投放后启动采样、采样恢复，以及飞书本人授权阻塞提示和已授权队列恢复的修复。这些服务端修复随个人任务服务更新生效。

Apple Silicon Mac（macOS 13 及以上）下载 `Inspire-Queue-macos-arm64-2014-unsigned.dmg`。此内部试用版采用 ad-hoc 签名，未进行 Apple 公证。
