# Inspire Queue 2.0.2013

服务器详情的「端口映射」新增「打开成果链接」。粘贴远程 Codex 提供的 8780 网页链接，即可建立本机转发、自动准备本人成果服务，并在浏览器打开。

- 同一成果服务的多个网页共用本机 8780，保留已有 fshare 链接及登记列表。
- 保存转发配置；SSH 断开后再次操作可重新连接。
- 建立转发后自动执行内置初始化脚本，已有服务直接复用，新账号自动安装并启动。
- 只监听本机回环地址；服务器使用本人私有连接，不开放 TCP 8780。端口冲突时保留原服务。
- 无需 Codex 或 sudo；远端需要 Python 3 和 SSH。

Apple Silicon Mac 内部版，ad-hoc 签名，未进行 Apple 公证。
